# 🎮 테트리스 (Streamlit)

현대 테트리스의 표준 규칙(SRS 회전·7-bag·락 딜레이·홀드·고스트)을 **파이썬으로 직접 구현한** Streamlit 앱입니다.
기존 JavaScript 게임을 iframe으로 감싼 래퍼가 아니라, 게임 엔진 전체가 파이썬으로 되어 있습니다.

## 특징

- **SRS 회전 + 킥 테이블** — 벽이나 바닥에 붙은 상태에서도 회전이 됩니다. I 미노는 전용 테이블을 사용하고, O 미노는 제자리에서 회전합니다.
- **7-bag 난수** — 7종을 한 번씩 담은 주머니를 섞어 소진합니다. 특정 블록이 오래 안 나오는 일이 없습니다.
- **락 딜레이 500ms** — 바닥에 닿은 뒤에도 밀어 넣을 여유가 있습니다. 조작할 때마다 유예가 초기화되지만 **최대 15회**로 제한해 무한정 버티는 것을 막습니다.
- **고스트 블록** — 떨어질 위치를 반투명하게 미리 표시합니다.
- **홀드** — 블록당 1회, 보관된 블록과 교체합니다.
- **다음 블록 3개 미리보기**
- **시작 레벨 선택** — 1~15레벨에서 시작할 수 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| `←` `→` | 좌우 이동 |
| `↓` | 소프트 드롭 (1칸당 1점) |
| `Space` | 하드 드롭 (1칸당 2점) |
| `↑` 또는 `X` | 시계 방향 회전 |
| `Z` | 반시계 방향 회전 |
| `C` | 홀드 |
| `P` | 일시정지 |
| `R` | 다시 시작 |

> Streamlit에는 키보드 이벤트 API가 없습니다. 키 입력은 보조 수단으로 붙여 둔 것이므로,
> 환경에 따라 듣지 않을 수 있습니다. **화면의 버튼이 기본 조작 수단입니다.**

## 점수 규칙

| 동시 삭제 | 명칭 | 점수 |
|---|---|---|
| 1줄 | Single | 100 × 레벨 |
| 2줄 | Double | 300 × 레벨 |
| 3줄 | Triple | 500 × 레벨 |
| 4줄 | Tetris | 800 × 레벨 |

10줄을 지울 때마다 레벨이 1 오르고 낙하 속도가 빨라집니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

Python 3.9 이상, Streamlit 1.37 이상이 필요합니다.
(`st.fragment(run_every=...)`가 1.37에서 정식 API가 되었습니다. 그보다 낮은 버전에서는 `experimental_fragment`로 대체 동작합니다.)

## 구현 노트

Streamlit은 상호작용마다 스크립트를 처음부터 다시 실행하는 구조라, 60fps 실시간 게임과는 궁합이 좋지 않습니다.
그래서 다음과 같이 우회했습니다.

**중력 — `st.fragment(run_every=0.12)`**
게임 화면만 120ms 주기로 다시 그립니다. 페이지 전체를 재실행하는 것보다 훨씬 가볍습니다.
낙하 타이밍은 `time.monotonic()`으로 관리하므로, 한 번의 갱신에서 여러 칸이 떨어질 수도 있고
탭이 비활성화됐다 돌아온 경우도 처리합니다.

**렌더링 — CSS 그리드**
캔버스 대신 200개의 `<div>`를 CSS 그리드로 배치합니다. 고스트는 `opacity`로 표현합니다.

**입력 — `on_click` 콜백**
버튼의 반환값을 검사하는 대신 `on_click` 콜백을 씁니다. 콜백은 화면을 다시 그리기 **전에** 실행되므로,
클릭 결과가 한 프레임 늦게 보이는 문제가 생기지 않습니다.

### 원본 대비 달라진 점

의도적으로 타협한 부분입니다.

| 항목 | 설명 |
|---|---|
| 낙하 간격 최소 100ms | 재실행 왕복 때문에 그보다 빠르면 의미가 없습니다. 높은 레벨에서 원본보다 느리지만, 블록이 여러 칸씩 순간이동하지 않습니다. |
| DAS/ARR 없음 | 버튼 클릭이 한 번에 한 칸입니다. 키를 누르고 있을 때의 연속 이동은 재현하지 않았습니다. |
| 최고 점수는 세션 한정 | `st.session_state`에 저장하므로 브라우저를 닫으면 사라집니다. |

## 검증

자동 테스트 **45개** 통과.

**게임 엔진 25개** — `app.py`를 import해 엔진을 직접 호출합니다.
(`if __name__ == "__main__"` 가드 덕분에 UI 없이 로직만 테스트할 수 있습니다.)

7-bag 규칙, 같은 시드의 재현성, 바닥에 붙은 I 미노의 SRS 킥, O 미노 위치 불변,
줄 삭제와 블록 하강, 테트리스 800점, 레벨에 따른 낙하 속도, 홀드 1회 제한,
고스트 위치의 정확성, 게임 오버 판정.

**UI 20개** — Streamlit 공식 테스트 도구 `AppTest`로 앱을 실제 실행합니다.

보드 200칸 렌더링, 버튼 9개 존재, 각 버튼 클릭이 게임 상태를 올바르게 바꾸는지,
일시정지 토글, 사이드바 슬라이더로 시작 레벨 적용.

## 파일 구조

```
.
├── app.py             게임 엔진 + Streamlit UI (단일 파일)
├── requirements.txt   streamlit>=1.37
└── README.md
```

`app.py`는 순수 로직(`Tetris` 클래스)과 UI(`main()`)가 분리되어 있어,
엔진만 import해서 테스트하거나 다른 프론트엔드에 붙일 수 있습니다.
